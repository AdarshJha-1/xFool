# buildsys

A small build system written in C.

## Goal

Understand the compilation pipeline by building a tool that discovers source files, compiles them, and produces an executable.

## Planned Features

* [ ] Discover source files
* [ ] Compile C files
* [ ] Generate object files
* [ ] Track dependencies
* [ ] Rebuild changed files
* [ ] Link objects
* [ ] Handle compiler flags
* [ ] Handle build errors
* [ ] Parallel builds
