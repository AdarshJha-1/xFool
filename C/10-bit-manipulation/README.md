# bitpack

A binary packing and serialization library written in C.

## Goal

Build utilities for encoding and decoding structured data at the byte and bit level.

## Planned Features

* [ ] Read/write bytes
* [ ] Read/write integers
* [ ] Bit fields
* [ ] Packing and unpacking
* [ ] Endianness conversion
* [ ] Variable-length integers
* [ ] Bounds checking
* [ ] Checksums
* [ ] Tests
* [ ] Benchmarks
