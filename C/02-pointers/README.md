# cvec

A dynamic vector library written in C.

## Goal

Build a reusable dynamic array that can store elements of arbitrary size.

## Planned Features

* [ ] Initialize and destroy vectors
* [ ] Push and remove elements
* [ ] Random access
* [ ] Automatic capacity growth
* [ ] Arbitrary element sizes
* [ ] Insert and erase
* [ ] Reserve capacity
* [ ] Shrink capacity
* [ ] Bounds checking in debug mode
* [ ] Tests
* [ ] Stress testing

## Status

Planned.
