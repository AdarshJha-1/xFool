# clib

A small personal C library built from reusable components.

## Goal

Build and maintain reusable C modules and understand how libraries, headers, object files and linking work.

## Planned Components

* [ ] Dynamic vector
* [ ] String library
* [ ] Hash table
* [ ] Memory utilities
* [ ] Binary serialization
* [ ] Logging
* [ ] Testing utilities

## Build

Produce a reusable library that can be linked into other C programs.
