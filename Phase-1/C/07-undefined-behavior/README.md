# ub-lab

A collection of intentionally broken C programs used to investigate undefined behavior and memory errors.

## Goal

Break C programs, observe what happens, and learn how to diagnose the failures.

## Areas

* [ ] Buffer overflows
* [ ] Use-after-free
* [ ] Double free
* [ ] Invalid memory access
* [ ] Uninitialized memory
* [ ] Integer overflow
* [ ] Invalid pointer operations
* [ ] Alignment violations
* [ ] Aliasing problems
* [ ] Optimization-dependent behavior

## Tools

* GDB
* AddressSanitizer
* UndefinedBehaviorSanitizer
* Valgrind
* GCC/Clang optimization levels
